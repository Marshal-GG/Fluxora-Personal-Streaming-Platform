1. **iOS player polish** — PIP + lockscreen / Now Playing card. `media_kit` uses MPV which doesn't bridge to `AVPictureInPictureController`; implementing iOS PIP requires either swapping the player backend or a custom AVFoundation surface.  iOS lockscreen needs `UIBackgroundModes = audio` in `Info.plist` and a verification pass — `audio_service` already supports it, just couldn't be tested without an iOS device this round.
